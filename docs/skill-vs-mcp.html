II.
İki kavram, iki farklı amaç
Definition · Mechanism · Analogy
Model Context Protocol — A
MCP Server
Claude'u dış dünyaya bağlayan standart bir konektör.
Ne yapar
Claude'a tool, resource ve prompt sunar; modelin kendi başına ulaşamayacağı dosya, veri ve servisleri erişilebilir kılar.
Yapısı
Bağımsız çalışan bir process. JSON-RPC üzerinden konuşur. Aynı server birden fazla istemciye servis verebilir.
Sınırı
Sadece kapasite verir; Claude'un bu kapasiteyi nasıl kullanacağına karışmaz.
— Analoji
"USB-C portu gibi. Hangi cihazı takarsan tak, aynı protokolle konuşur. MCP de Claude'a takılan standart bir uçtur."
Behavioral Instruction Set — B
Skill
Claude'a belirli bir konuda nasıl davranacağını öğreten talimat paketi.
Ne yapar
Bir uzmanlık alanını tarif eder: hangi kurallar geçerli, hangi adımları takip et, çıktı nasıl olmalı, neyi atla.
Yapısı
Markdown SKILL.md + opsiyonel referans dosyaları. Konu açıldığında Claude bunu yükler ve yönergeyi izler.
Sınırı
Sadece davranış tanımlar; harici sistemlere kendi başına ulaşamaz — bunun için MCP'ye veya araçlara güvenir.
— Analoji
"Yeni bir mühendise verilen onboarding klasörü gibi. Şirket kuralları, kontrol listeleri, 'biz burada şöyle yaparız' dökümanı."

IV.
Bir gerçek örnek: MISRA C Reviewer
Skill + MCP — birlikte çalışırken
Skill —
MISRA C Reviewer
Embedded C kodunu MISRA kurallarına göre denetlemeyi bilen davranış paketi. Hangi rule'a bakılır, ihlal nasıl raporlanır, hangi sırayla incelenir — hepsi burada tanımlı.
MCP Server —
Datasheet & Manual Reference
Kullanıcının yüklediği MCU datasheet'lerini ve referans manuel'larını Claude'a açar. Skill ihtiyaç duyduğunda doğru sayfayı, doğru registeri, doğru pin tanımını oradan çeker.
— İş akışı
Beş adımda nasıl çalışıyor
Workflow
Step-by-step
01
Kullanıcı
Kodu & datasheet'i yükler
"STM32 için yazdığım bu sürücüyü MISRA'ya göre incele."
02
Claude
Skill'i devreye alır
MISRA C Reviewer talimatlarını okur, denetim planını çıkarır.
03
MCP
Referansı sağlar
İlgili register, timing veya pin bilgisini datasheet'ten Claude'a getirir.
04
Skill
Kuralla eşleştirir
Kod + datasheet bilgisini MISRA rule setiyle karşılaştırır, ihlali tespit eder.
05
Claude
Raporu yazar
İhlal · gerekçe · datasheet referansı · önerilen düzeltme.
Sonuç —
Sadece bir kural ihlali listesi değil; hangi register'a, hangi datasheet sayfasına ve hangi MISRA kuralına dayanarak gerekçelendirilmiş, izlenebilir bir denetim raporu.
